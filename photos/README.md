# Photos

Drop wedding website photos in this folder.

Suggested filenames:

- `hero.jpg` for the main homepage background
- `couple-1.jpg`, `couple-2.jpg`, etc. for couple photos
- `venue-1.jpg`, `venue-2.jpg`, etc. for venue or area photos
- `hotel-1.jpg`, `area-1.jpg`, etc. for travel recommendations

Use `.jpg`, `.jpeg`, `.png`, or `.webp`.

After adding photos, update the references in `index.html` or `css/custom.css`.
